# Partcounter R001.19 – Hilfe-Screenshots

Dieser Ordner enthält die **originalen Screenshots aus der realen Partcounter-Anwendung** für die integrierte Hilfe.

## Regeln

- Dateiname muss exakt dem `Screenshot:`-Eintrag in `PARTCOUNTER_HILFE_R001_19.md` entsprechen.
- Bevorzugt PNG.
- Windows-Skalierung möglichst 100 % oder 125 %, durchgehend für alle Aufnahmen gleich.
- Fenster möglichst in gleicher Größe aufnehmen, ideal ca. 1600–1800 px Breite.
- Demo-/Testdaten verwenden, keine echten Kundendaten, Passwörter, Tokens, Zertifikatpfade oder vertraulichen Netzwerkfreigaben zeigen.
- Wenn ein Screenshot einen Windows-Benutzerpfad enthält, persönlichen Benutzernamen vor Verwendung im Handbuch entfernen oder anonymisieren.
- Mauszeiger nur dann sichtbar lassen, wenn er für die Erklärung relevant ist.
- Keine künstlich nachgebauten UI-Grafiken verwenden. Die Hilfe soll echte Partcounter-Oberflächen zeigen.

Sobald eine referenzierte Bilddatei hier vorhanden und als WPF-Resource eingebettet ist, zeigt `HelpCenterWindow` sie automatisch im zugehörigen Hilfethema an. Fehlt die Datei, erscheint weiterhin der vorbereitete Screenshot-Slot mit Aufnahmeanweisung.
